Sobre o projeto

Esse é o projeto de uma Rede Social desenvolvido em HTML, CSS e PHP.

Aqui é possível cadastrar usuários, criar postagens e fazer comentários.

Funcionalidades

  • Cadastrar usuários
  • Listar usuários
  • Cadastrar postagens
  • Visualizar postagens
  • Adicionar comentários
